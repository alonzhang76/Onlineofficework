# 发票与付款系统

本地 Web 应用：PDF 发票自动识别录入 → 会计科目自动归类 → 台账查询/编辑/统计/导出。

## 启动方式

双击 `start.bat`，或命令行执行：

```
C:\Users\MI\.workbuddy\binaries\python\envs\default\Scripts\python.exe -X utf8 app.py
```

浏览器访问 **http://127.0.0.1:8686**

## 功能说明

| 模块 | 功能 |
|------|------|
| 发票录入 | 拖拽/批量上传 PDF（数电票、增值税专票/普票），自动识别发票号、日期、销售方、品名、金额、税率、税额、价税合计；支持手工录入兜底（扫描件无法解析时） |
| 查重 | 数据库层 `UNIQUE` 约束 + 上传前校验，发票号码唯一，重复上传直接拒绝并提示已有台账编号 |
| 科目归类 | 按品名/销售方关键词自动匹配会计科目（差旅费-交通费/住宿费、办公费、业务招待费、通讯费、咨询费、原材料、固定资产等 16 类），可手工修改 |
| 发票台账 | 多条件查询（关键词/日期区间/发票类型/科目/状态/金额），分页排序，金额合计汇总，单条编辑/删除，批量改状态（待审核→已通过→已入账），发票原件下载 |
| 统计报表 | 按科目/月份/状态/发票类型汇总，抵扣税额合计 |
| 导出 | 一键导出 Excel 台账 |

## 数据与文件

- 数据库：`reimbursement.db`（SQLite，含 WAL 模式）
- 发票原件：`uploads/发票号.pdf`（按发票号命名）
- 被删除的文件进入 `uploads/.trash/`，确认无用后可手动清空

## 技术栈

Python 3.13 (Flask + pdfplumber + openpyxl) + SQLite + 原生 JS 单页前端。

## 已知边界

- 仅支持**文本型** PDF 发票；扫描件/图片型发票会提示改用手工录入（可后续接入 OCR）
- 科目归类为规则匹配（建议性），最终以会计确认的科目为准
- 生产部署建议更换 WSGI 服务器（如 waitress）并做访问控制

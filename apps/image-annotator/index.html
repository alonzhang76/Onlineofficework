☀ 亮度 / 对比度
请先上传图片，然后在图片上添加标注
💡 任意工具下光标移到标注上即可直接拖动/选中；选中后：滚轮缩放、方向键旋转、] [ 改字号、双击编辑文字；Ctrl+Z/Y 撤销重做、Ctrl+C/V 复制粘贴、右键删除、按住空格看原图、Esc 中断工具、? 帮助；裁剪 Enter 确认 / Esc 取消
⌨ 快捷键与操作说明
选择 / 编辑自动识别：任意工具下光标移到已有标注上即可直接拖动/选中（裁剪、马赛克、画笔、插图除外）；选中后拖动移位、滚轮缩放、方向键旋转（Shift 微调 1°）、+ / − 整体缩放、Delete 删除
文字大小选中文字/气泡后按 ] 放大字号、[ 缩小字号（框不变）；双击进入文字编辑，Ctrl+Enter 保存，Esc 取消
签名✍ 签名（行书）：拖拽确定大小后输入内容，以中文行书显示；双击可修改文字，选中后滚轮缩放、方向键旋转、] [ 改字号
全图水印图像 → 💧 全图水印：输入文字后以 45° 半透明平铺全图（导出时包含）；再次打开可更换，留空确定即移除；水印存在时可用导航栏「水印」滑块实时调节透明度
撤销 / 重做Ctrl+Z 撤销，Ctrl+Y（或 Ctrl+Shift+Z）重做；按 Esc 中断当前绘图工具，回到移动工具
复制 / 粘贴选中标注后 Ctrl+C 复制，Ctrl+V 在偏移 16px 处粘贴
删除标注选中后按 Delete，或直接在标注上点右键
查看原图按住空格键临时隐藏所有标注，松开恢复
尺寸测量↔ 直线长自动显示长度；选中一条线后用「操作 → 校准比例尺」输入实际 cm；双击尺寸线可自定义文字（清空则恢复自动长度）
裁剪图像 → 裁剪图片，拖拽框选后 Enter 确认、Esc 取消（标注自动保留并随裁剪平移）
画笔 / 序号🖊 画笔为半透明荧光笔效果；① 序号标注点击即自动编号，随标注增删自动重排
导出底部可保存 PNG / JPG 或复制到剪贴板，直接粘贴进微信 / 邮件

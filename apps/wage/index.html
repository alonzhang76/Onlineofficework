数据概览
备份说明

1. 备份文件为 JSON 格式，包含全部五类数据，文件名格式为 工资数据备份_YYYYMMDD.json
2. 恢复时请选择之前导出的 .json 备份文件，系统会自动识别并导入
3. 建议每周或每月做一次定期备份，重要操作前也建议先备份
4. 如需在 Excel 中查看数据，可使用各模块的"导出Excel"功能
5. 清除浏览器缓存或更换浏览器会导致数据丢失，请务必做好备份

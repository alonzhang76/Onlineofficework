## 表单高度统一 + 弹层滚动修复（2026-09-10 17:35）
- 用户反馈三个问题：①输入框高度不统一、文字显示不全 ②备注等多行文本在网页版可调、小程序里固定死看不到全部 ③编辑弹层打开后固定不动，滑动时背景页面在动
- **根因**：
  · ①小程序 input 不给显式高度就用组件默认高度 → 同表单高低不齐、文字上下被裁；picker 展示值是纯 view，与 input 高度对不上

## 修复弹层真机不滚动（2026-09-10 18:50）
- 用户反馈（附真机截图）：编辑订单弹层仍不能上下滑动、字段显示不完整 —— 输入框新样式已生效，说明 scroll-view 已在但没滚
- **根因（查证社区资料确认）**：微信小程序 scroll-view 必须有「确定的物理高度」才滚动；`flex: 1 + min-height: 0` 在开发者工具正常、**真机上高度解析成内容高度**（CSDN/博客园多篇同款案例），于是被 .sheet 的 overflow:hidden 裁掉 → 「看得到但滑不动」
- **修复**：把确定高度直接给 scroll-view 自身 —— .sheet-body 加 `max-height: calc(85vh - 110rpx)`（85vh 弹层上限 − 固定标题约102rpx），.modal-body 加 `calc(80vh - 110rpx)`；内容少=按内容高（弹层矮），内容多=钳到上限可滚动；另加 overscroll-behavior:contain 防滚动链
- 保留 flex:1 1 auto（部分机型 flex 生效时由它适配）；catchtouchmove 保留（事件先到 scroll-view 再冒泡到 mask，不拦截子组件原生滚动，是社区标准写法）
